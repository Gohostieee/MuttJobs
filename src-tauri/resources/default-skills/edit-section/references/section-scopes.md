# MuttJobs section scopes

Resolve standard sections beneath these roots:

- Summary: `summary`
- Experience: `sections.experience`
- Education: `sections.education`
- Projects: `sections.projects`
- Skills: `sections.skills`
- Languages: `sections.languages`
- Awards: `sections.awards`
- Certifications: `sections.certifications`
- Publications: `sections.publications`
- Volunteer: `sections.volunteer`
- References: `sections.references`
- Profiles: `sections.profiles`
- Custom sections: one exact entry under `customSections`

Section titles and descriptions are rich-text HTML when stored that way. Preserve valid structure. Do not alter section layout settings such as columns, alignment, enabled, hidden, keep-together, or page-start behavior unless the user explicitly names that setting as the target.

For content-polish requests, edit content or description fields, not historical identity fields.
