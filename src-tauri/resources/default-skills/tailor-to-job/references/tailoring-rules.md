# Conservative tailoring rules

1. Extract required and preferred capabilities from the job description.
2. Map them to direct, partial, weak, or absent resume evidence.
3. Promote direct evidence before partial evidence.
4. Use the employer's terminology only when it truthfully describes existing candidate evidence.
5. Keep unsupported requirements in the response as gaps; never place them in the resume.
6. Prefer reordering and concise reframing over adding content.
7. Retain distinctive accomplishments even when their vocabulary differs from the posting.
8. Preserve every source fact, including evidence that is not a priority for this job; relevance changes emphasis, not factual coverage.
9. Audit the result item by item and bullet by bullet. Do not delete, hide, or collapse content unless all original facts and nuances remain explicitly represented.
10. Do not force a page count or bullet cap. Factual preservation wins whenever it conflicts with brevity.

Allowed example: make an existing Go event-processing accomplishment more prominent for a distributed-systems role.

Prohibited example: add Kubernetes because the posting requests it when the resume and user provide no Kubernetes evidence.
